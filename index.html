Numerical Analysis Pipeline
① EDGE DETECTION [OpenCV + numpy] Cyan threshold isolates stroke pixels per frame. Centroid of new pixels tracks pen tip (~90% frame capture). Morphological skeletonization (Zhang-Suen) reduces stroke to 1-pixel centerline. Sobel operator: G = √(Gx² + Gy²) finds geometric stroke boundaries.
② INTERPOLATION [scipy CubicSpline] Arc-length parameterization: s[i] = s[i-1] + ‖pos[i] - pos[i-1]‖. Removes speed dependency. CubicSpline fits piecewise cubic polynomials, C2-continuous at every knot. Passes exactly through all input points (residual at knots = 0).
③ DERIVATIVES [numpy.gradient] Central difference on actual timestamps (non-uniform spacing): vx[i] = (x[i+1]-x[i-1]) / (t[i+1]-t[i-1]). Computes velocity, acceleration, and ds/dt. Savitzky-Golay smoothing preserves peak shapes.
④ ROOTFINDING [bisection + Newton-Raphson] Finds zeros of ds/dt where speed has local minimum (pen stops). True bisection: f(a)·f(b) < 0, halve interval until |b-a| < 1e-6. Newton-Raphson refines: x_{n+1} = x_n - f(x_n)/f'(x_n) using analytic CubicSpline derivative.

③ Derivatives — Velocity & Acceleration
Normalized speed profile (cyan)
vx[i] = (x[i+1]-x[i-1]) / (t[i+1]-t[i-1])  |  speed = √(vx²+vy²)  |  Savitzky-Golay smoothed
Normalized acceleration profile (orange)
ax[i] = (vx[i+1]-vx[i-1]) / (t[i+1]-t[i-1])  |  accel = √(ax²+ay²)
④ Rootfinding — Zeros of ds/dt (Speed Minima)
Speed profile — local minima found by bisection + Newton-Raphson (yellow ▼)
Find x where ds/dt=0 (speed minimum)  |  Bisection: f(a)·f(mid)<0 → halve interval  |  Newton: x_{n+1}=x_n - f(x_n)/f'(x_n)  |  ε=1e-6
ds/dt profile — signed rate of speed change
ds/dt = d(speed)/dt  |  ds/dt < 0: decelerating  |  ds/dt > 0: accelerating  |  ds/dt = 0: speed minimum
